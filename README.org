Can plain text keep its source while feeling almost rendered?

~markdown-ts-appear~ builds on Emacs 31's Tree-sitter-powered
~markdown-ts-mode~ to do both: Markdown stays visually rendered while reading,
then the smallest element at point smoothly reveals its source for editing.
The characters themselves become the interface: headings, quotes, code blocks,
tables, and callouts are shaped with fonts, spacing, Unicode, and native display
properties, not a separate preview or browser-like UI.  Optional MathJax support
renders LaTeX fragments asynchronously.

* Highlights

- Smooth, syntax-aware reveal powered by Tree-sitter
- Focused editing: reveal only the element at point
- An interface made from characters, not browser-like widgets
- Optional decorations for links, code fences, quotes, callouts, and tables
- Optional asynchronous LaTeX preview through MathJax
- Insert-state-aware reveal for Evil and Meow

* Requirements

- Emacs 31.1 or newer
- The ~markdown~ and ~markdown-inline~ Tree-sitter grammars

Math preview is disabled by default.  It additionally requires the optional
~mathjax~ Emacs package and Node.js, neither of which is installed by this
package.  Preview is attempted only in a graphical SVG-capable session.

* Installation

With ~use-package~ and ~package-vc~:

#+begin_src emacs-lisp
(use-package markdown-ts-appear
  :vc (markdown-ts-appear
       :url "https://github.com/Thysrael/markdown-ts-appear"
       :rev :newest)
  :hook (markdown-ts-mode . markdown-ts-appear-mode))
#+end_src

Visual decorations are opt-in; without further configuration, elements retain
their normal ~markdown-ts-mode~ appearance.  Wiki links such as
~[[target|alias]]~ are supported by the grammar's default configuration.

* Customization

One possible setup:

#+begin_src emacs-lisp
(setq markdown-ts-appear-link-icon '("" . "↗")
      markdown-ts-appear-image-icon '("" . "▧")
      markdown-ts-appear-code-fence-style 'connected
      markdown-ts-appear-label-caps '("" . "")
      markdown-ts-appear-render-callouts t
      markdown-ts-appear-block-quote-marker "▎"
      markdown-ts-appear-table-style 'unicode)
#+end_src

Icons and quote markers are plain strings, with no icon-package dependency.  A
cons cell such as ~("" . "↗")~ uses the first string when its characters are
displayable and otherwise falls back to the second.

Key options:

- ~markdown-ts-appear-trigger~: reveal always, or only in Evil/Meow insert state.
- ~markdown-ts-appear-link-icon~, ~markdown-ts-appear-image-icon~, and
  ~markdown-ts-appear-wikilink-icon~: add link prefix icons.
- ~markdown-ts-appear-code-fence-style~: use raw fences or connected Unicode
  lines.
- ~markdown-ts-appear-label-caps~: surround code-language and callout labels.
- ~markdown-ts-appear-render-callouts~: render callout labels such as
  ~[!WARNING]-~; folding is not included.
- ~markdown-ts-appear-block-quote-marker~: replace block quote markers.
- ~markdown-ts-appear-table-style~: use raw or Unicode table delimiters without
  adding or aligning borders.

Re-enable ~markdown-ts-appear-mode~ after changing structural decoration
options in an active buffer.

* Math Preview

Install and opt into the optional MathJax integration separately:

#+begin_src emacs-lisp
(use-package mathjax
  :ensure t
  :defer t)

(setq markdown-ts-appear-enable-math-preview t)
#+end_src

If the option is enabled without ~mathjax~, the main appear mode remains active
and reports that math preview is unavailable.  Re-enable the main mode after
installing ~mathjax~ or changing this option.

Related options are ~markdown-ts-appear-math-timeout~,
~markdown-ts-appear-center-display-math~, and ~markdown-ts-appear-math-scale~.

To render image files themselves, also enable the built-in
~markdown-ts-inline-images~ option or run ~markdown-ts-toggle-inline-images~.

* Modal Editors

Evil and Meow are optional.  To reveal source only while editing, select the
corresponding insert-state trigger:

For Evil:

#+begin_src emacs-lisp
(setq markdown-ts-appear-trigger 'evil-insert)
#+end_src

For Meow:

#+begin_src emacs-lisp
(setq markdown-ts-appear-trigger 'meow-insert)
#+end_src

* Demo

Open [[file:examples/demo.md][examples/demo.md]] in ~markdown-ts-mode~ to exercise headings, inline markup,
links, images, lists, tasks, tables, MathJax previews, and other revealable
elements.  Math examples use the delimiters supported by the Markdown grammar:
~$...$~ and ~$$...$$~.  The local SVG keeps the image example independent of
the network.

* Development

Run the tests with:

#+begin_src shell
MARKDOWN_TS_APPEAR_REQUIRE_GRAMMARS=1 \
emacs --batch -Q -L . \
  --eval '(progn (require (quote package)) (package-initialize))' \
  -l test/markdown-ts-appear-test.el \
  -f ert-run-tests-batch-and-exit
#+end_src

Without ~MARKDOWN_TS_APPEAR_REQUIRE_GRAMMARS~, tests that require the Markdown
Tree-sitter grammars are skipped when the grammars are unavailable.  To also
require the optional package, Node.js, and a real MathJax-to-SVG render, add
~MARKDOWN_TS_APPEAR_REQUIRE_MATHJAX=1~ before the command.

CI covers the latest and baseline Markdown grammars, real MathJax-to-SVG
rendering, Emacs snapshots, and compatibility with the private
~markdown-ts-mode~ functions used by the package.
