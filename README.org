Reveal the source of the inline Markdown element at point in Emacs 31's
built-in ~markdown-ts-mode~.

This fork deliberately does one job.  It reveals emphasis, strong emphasis,
strikethrough, code spans, links, images, autolinks, escapes, entities, and
Wiki links while they are edited, then restores the host mode's concealed
presentation.  It does not style document structure, add icons, render image
labels, or preview LaTeX.

* Requirements

- Emacs 31.1 or newer
- The ~markdown~ and ~markdown-inline~ Tree-sitter grammars

There are no package dependencies beyond built-in Emacs libraries.

* Installation

With ~use-package~ and ~package-vc~:

#+begin_src emacs-lisp
(use-package markdown-ts-appear
  :vc (markdown-ts-appear
       :url "https://github.com/hyperZphere/markdown-ts-appear"
       :rev :newest)
  :hook (markdown-ts-mode . markdown-ts-appear-mode))
#+end_src

* Activation

The default ~always~ trigger follows point whenever the minor mode is active.
For a modal editor, choose ~manual~ and connect the public start and stop
commands to its editing-state hooks:

#+begin_src emacs-lisp
(setq markdown-ts-appear-trigger 'manual)
(add-hook 'my-insert-state-entry-hook
          #'markdown-ts-appear-manual-start)
(add-hook 'my-insert-state-exit-hook
          #'markdown-ts-appear-manual-stop)
#+end_src

The package contains no Evil- or Meow-specific behavior; either editor can use
the same manual interface.

* Scope and cooperation

~markdown-ts-appear-mode~ is independent of appearance packages.  It can be
used by itself or alongside ~markdown-ts-modern-mode~:

- ~markdown-ts-modern-mode~ decides how Markdown looks.
- ~markdown-ts-appear-mode~ decides when hidden inline source becomes editable.

Neither mode requires the other.  Structural elements such as headings,
lists, task boxes, tables, thematic breaks, and fenced code blocks remain the
responsibility of ~markdown-ts-mode~ and appearance packages.  LaTeX preview
belongs to a dedicated fragment-preview package.

* Development

Run the tests in an Emacs environment containing both Markdown grammars:

#+begin_src shell
emacs --batch -Q -L . \
  -l test/markdown-ts-appear-test.el \
  -f ert-run-tests-batch-and-exit
#+end_src
